# Exploratory-Data-Analysis

COVID-19 Patient Risk Analysis is a data science and machine learning project designed to examine patient characteristics and estimate the risk of an adverse COVID-19 outcome. The workflow includes dataset inspection, exploratory data analysis, data cleaning, missing-value and duplicate handling, outlier review, categorical encoding, and numerical scaling where appropriate.
